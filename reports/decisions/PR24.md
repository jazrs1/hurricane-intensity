## What it does (your spec)

- **`check.py` with no flag = FAST:** protected hashes first, then `pytest -m "not slow"` (unit tests and list invariants), then the git and gitignore checks.
- **`check.py --full`:** every section check.py ran before, in the same order (all tests, the evaluate.py smoke run, hashes after the smoke run). `--e2e` is unchanged.
- **Slow-test rule:** a test is marked slow if any of its runs took 1 s or more. That covers 89 functions (128 test IDs).
- **The output names the mode:** the first line reads "mode: FAST (merges require --full)", and the last line "PASS FAST total" or "PASS FULL total".
- **Drift warning:** `--full` prints a warning, without failing, naming any unmarked test of 1.5 s or more, so new slow tests don't quietly creep into FAST. The 1.5 s threshold is my choice; it stops jitter at 1.0 s from triggering it.
