# PR #44: HEP gate (d), East Pacific reader seal

**Needs John: merge PR #44**, pinned to **ec4c1b8**. Recommendation: **yes**.

## What it does

- **The seal:** the East Pacific HURDAT2 reader refuses the H-EP storms and the concurrency exclusions (Octave and Raymond 2025).
  - The list is read when the reader is called: `storms_holdout_hep.txt` plus `config.HEP_CONCURRENT_IDS`.
  - A missing or empty list stops it with an error. It never seals nothing.
- **The only exception** is the sealed build into `data/hep_sealed`.
  - It goes through a private function that re-checks the folder, the list membership and the nepac pin before writing.
  - There is no flag, and a test pins it to a single caller.
- **The positions-only reader for E3's concurrency gate:**
  - it returns only time, latitude and longitude, for every fix;
  - no wind, no status, no logging;
  - errors give only the storm ID and line number.
- **Files:** config.py, hurdat2.py, pipeline.py, tests/test_list_invariants.py, and the new tests/test_hurdat2_seal.py (54 tests, all on synthetic fixtures).
  - Every test confirms the Atlantic cache's hash is unchanged.
  - All 12 deliberately broken versions of the code fail a test.
- **Side effect:** `reports/v2_survey/hep/reference_geometry.py` now refuses if rerun, which is consistent with the seal.
